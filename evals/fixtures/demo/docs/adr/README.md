## Notes

- The index is derived from the files. Where they disagree, the files win.
- Numbers are sequential and never reused.
- An Accepted ADR is not edited. A change of mind is a new ADR that supersedes it.
- Status values: Proposed, Accepted, Rejected, Superseded.
- An ADR is written only when all three hold: the consequences outlive the change, a
  competent engineer could have chosen otherwise, and the reason is not recoverable from the
  code.
