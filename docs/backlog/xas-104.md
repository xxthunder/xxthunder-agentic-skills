# [XAS-104] The backlog is also found in doc/backlog

**Status**: Open
**Priority**: Low
**Component**: `plugins/xxthunder-dev-skills/scripts/backlog.py` (`find_backlog`, the `origin/HEAD` archive), `plugins/xxthunder-dev-skills/scripts/board.py` (`item_url`), `plugins/xxthunder-dev-skills/hooks/session-start`, the `backlog-ops` and `refinement` skill texts

**Summary**:
As the author of a repository that keeps all its documentation in `doc/`, I want the backlog skills to find `doc/backlog/`, so that the backlog can sit next to the rest of the documentation.

**Description**:
`backlog.py` knows one location, `docs/backlog` (`BACKLOG_IN_REPO`). Three places depend on it:

- `find_backlog` walks up from the working directory and looks only for `docs/backlog/README.md`.
- The read of another repository at `origin/HEAD` archives only `docs/backlog`, and `board.py`'s `item_url` builds the card link from the same constant.
- The `SessionStart` hook reports a backlog only when `docs/backlog` exists.

A repository with its documentation in `doc/` must then pass `--dir doc/backlog` on every call. The skills do not do that themselves, so a pull, a close or a board move fails there. The trigger is DEMO-011 in asf-closed-loop-demo, which moves that repository's backlog to `doc/backlog/`.

**Scope Decisions**:
- Discovery, not a setting. The author first asked for an optional per-repository setting. ADR-0006 decides that record locations are discovered and never configured, and that a repository with a document elsewhere gets a longer search order instead. Its text covers the architecture document and the ADR log; its reasoning, no per-repository upkeep, holds for the backlog too. The author chose the search order on 2026-11-23.
- The search order is stated once, in `backlog.py`; the hook and the skill texts follow it, as ADR-0006 asks for the other records.
- `--dir` stays for a backlog in any other place.

**Acceptance Criteria**:
- [ ] `backlog.py` finds the backlog in `docs/backlog/`, and else in `doc/backlog/`, from anywhere inside the repository.
- [ ] When both directories hold a `README.md`, `backlog.py` exits non-zero and names both paths.
- [ ] The read at `origin/HEAD` finds an item in `doc/backlog/` of another repository.
- [ ] `board.py` links a card to the item's real path, `doc/backlog/` included.
- [ ] The `SessionStart` hook reports a backlog in `doc/backlog/`.
- [ ] The `backlog-ops` and `refinement` texts and `backlog-format.md` name the search order, not only `docs/backlog`.
- [ ] Tests cover each criterion above; the gate is green on both CI matrix jobs.
- [ ] The plugin version is bumped as a minor change.
