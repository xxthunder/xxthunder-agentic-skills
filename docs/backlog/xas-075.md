# [XAS-075] backlog.py loses show --in-progress, which no skill calls any more

**Status**: Open
**Priority**: Low
**Component**: `plugins/xxthunder-dev-skills/scripts/backlog.py`, `tests/dev/scripts/test_backlog.py`, `skills/refinement/references/backlog-format.md`
**Related**: [XAS-060](xas-060.md)

**Summary**:
As the maintainer, I want `backlog.py show --in-progress` removed now that no skill calls it, so that the script carries no dead option.

**Description**:
Since XAS-060, `backlog-ops` hands the board move to `board.py pull`, which decides itself, through `is_work_in_progress`, that an epic or the refinement item gets no card. The `--in-progress` option of `backlog.py show` has no caller left in any skill. `refinement/references/backlog-format.md` (around lines 104 and 280) still names it as what recognises the refinement item.

**Acceptance Criteria**:
- [ ] `backlog.py show` has no `--in-progress` option, and its tests go with it
- [ ] `backlog-format.md` names `board.py` / `is_work_in_progress` where it named the option
- [ ] The plugin's version is bumped in `plugin.json` and `marketplace.json`
