# [XAS-073] A script writes the board table

**Status**: Open
**Priority**: Low
**Component**: `plugins/xxthunder-dev-skills/skills/next/SKILL.md`, `plugins/xxthunder-dev-skills/skills/backlog-ops/SKILL.md`, `plugins/xxthunder-dev-skills/scripts/`
**Related**: [XAS-055](xas-055.md)

**Summary**:
As the author, I want `next put` and the board move of `backlog-ops` to write the board
table through a script, so that the board's layout rules hold on every write.

**Description**:
The board contract keeps two independent columns, each packed from the top, and drops a
row whose two cells are both empty. Both skills edit the table by hand. On 2026-11-05 a
`put` inserted a new row with an empty *In Progress* cell, which left a gap in that column.
It had to be repacked before the commit. Placing a card at a rank, moving it between
columns and repacking are deterministic, and the general rubric's "mechanical work is code"
asks for a script.

**Acceptance Criteria**:
- [ ] A script places, moves and drops a card in a board table and repacks both columns
- [ ] `next put`/`drop` and the board move of `backlog-ops` call it instead of editing the
      table by hand
- [ ] Tests cover put at a rank, a pull from *Next* to *In Progress*, and a drop
