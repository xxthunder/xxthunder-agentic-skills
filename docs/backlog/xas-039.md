# [XAS-039] Derive the backlog TOC from the items

**Status**: In Progress
**Priority**: Medium
**Component**: `plugins/xxthunder-dev-skills/scripts/` (new `backlog.py`), `plugins/xxthunder-dev-skills/skills/refinement/`, `plugins/xxthunder-dev-skills/skills/backlog-ops/`, `tests/dev/backlog/`

**Related**: [XAS-033](xas-033.md) (the TOC invariant tests whose checks move into the script), [XAS-004a](xas-004a.md) (pre-commit validation)

**Summary**:
As the author, I want every mechanical backlog operation done by a tested
script, so that the table of contents is always right and an agent writes only
what needs judgement.

**Description**:
On 2026-10-01 `develop` went red: XAS-038 was filed above XAS-036 in
`### Open`, and `check_sections_are_id_sorted` failed in CI after the push.
Nothing sorts the TOC. An agent edits the Markdown by hand and follows prose
rules: `backlog-ops` says "insert at the right position" when it moves an item,
while `refinement`'s New Ideas step only says "Add to backlog after user
approval". The test detects the mistake, and only after the push.

The status is also kept twice: in the item's `**Status**:` line and in the
README section its link sits in. `check_status_matches_section` exists only
because the two can disagree.

The items become the truth, and a script derives the README TOC from them. The
same script takes over the other mechanical steps the skills do by hand today:
allocating an ID and setting a status.

The script runs on the workbench, against this repository and against every
other repository checked out there. Five backlogs exist today: XAS, ZK, ARDS,
SC and HSH. All keep one file per item, a `**Status**:` line in each, and
`### Open`, `### In Progress` and `### Done` sections. They differ in:
- SC: a `### Superseded` section whose lines carry "— replaced by" notes;
  In Progress before Open; a checklist (`### Closing an item`) inside the TOC
  block; 17 legacy items with other prefixes (`BUG`, `CHORE`, `CI`, `FEAT`,
  `REFACT`) next to the `SC` ones.
- XAS and HSH: some legacy items are `Done` without a date.

**Scope Decisions**:
- **Items are the truth** (author, 2026-10-03). Everything the README says about
  an item comes from the item. This reverses `backlog-format.md`, which today
  calls the README the single source of truth for status, so it gets an ADR.
- **One fixed section order for every repo** (author, 2026-10-03): Open,
  In Progress, Done, then Superseded when an item has that status. Four of the
  five backlogs already use this order.
- **IDs descending, newest on top** (author, 2026-10-03), in every section. An
  epic sorts below its own substories: `XAS-026h` … `XAS-026a`, `XAS-026`.
  The sort key is prefix, then number, then letter, so SC's legacy prefixes
  form blocks of their own.
- **A TOC line holds the link to the item, its ID and its title, nothing
  else.** The title is the item heading minus the `✅ DONE -` marker. Notes such as SC's
  "— replaced by" are not carried over; the item states what replaced it, and
  SC's superseded items already do.
- **Python with PEP 723 metadata, run with `uv run`**: `uv` is on the workbench
  and on every host (author, 2026-10-03).
- **Only the commands the skills need now**: `next-id`, `set-status`, `toc`,
  `check`. Searching stays with `grep` (author, 2026-10-03).
- **Nothing is dropped silently**: `toc` replaces only the TOC block, and it
  refuses when the block holds anything it cannot derive from an item.
- **The backlog is found, not configured**, following
  [ADR-0006](../adr/0006-record-locations-are-discovered.md): `docs/backlog/`
  from the repository root, or the directory given with `--dir`.

**Findings in the other backlogs** (`check` on the workbench, 2026-10-03):
- ZK, ARDS, SC and HSH: the TOC differs from the items. `toc` resolves it the
  next time either skill runs there. In ZK it flattens the indented
  substories; in SC it drops the "— replaced by" notes, which the superseded
  items already state.
- ZK: `zk-021.md` and `zk-022.md` link to `../../homelab/…`, which no longer
  exists. ZK has to change.
- HSH: HSH-056 is Done while HSH-056a is open, and HSH-058 is Done while
  HSH-058b and HSH-058c are open. HSH has to change.

**Acceptance Criteria**:
- [ ] An ADR records that the items are the source of truth and the TOC is derived; `backlog-format.md` and this backlog's Notes say the same
- [ ] `scripts/backlog.py` provides `next-id [<parent>]`, `set-status <ID> <status>`, `toc` and `check`, written test-first
- [ ] `set-status` writes the status line, the date for Done and Superseded, and the `✅ DONE -` heading marker; it refuses to set an epic to Done while a substory is not Done
- [ ] `toc` writes the sections in the fixed order with IDs descending, and a second run changes nothing
- [ ] `toc` refuses with a non-zero exit, naming the line, when the TOC block holds content that no item produces
- [ ] `check` reports everything `test_backlog_toc.py` reports today; the test uses the script's parser instead of its own copy, and the sort check expects descending IDs
- [ ] `refinement` (New Ideas) and `backlog-ops` (pull, complete) call the script for IDs, status and TOC, and no longer edit the TOC by hand
- [ ] This repository's README is regenerated with `toc`
- [ ] `check` has run against the ZK, ARDS, SC and HSH backlogs on the workbench; each finding is either resolved by `toc` or listed here with the repository that has to change
- [ ] Plugin version bumped (minor) in `plugin.json` and `marketplace.json`
- [ ] Both CI matrix jobs are green
