# [XAS-096] The evidence package's steps name the pull request without its number

**Status**: Open
**Priority**: Low
**Component**: `plugins/xxthunder-dev-skills/skills/closed-loop/`
**Related**: [XAS-092](xas-092.md) (the run that found it)

**Summary**:
As the author, I want every command under *Your steps* to run as written, so that I can
copy it from the pull request without filling in a placeholder.

**Description**:
The loop writes the evidence package before it opens the pull request, so the pull
request's number is not known yet. In the first run of DEMO-002 in
xxthunder/asf-closed-loop-demo (2026-11-13), *Your steps* said
`gh pr merge <number> --rebase --repo xxthunder/asf-closed-loop-demo`. `gh pr merge` also
takes the branch name, which the loop knows from the start.

**Acceptance Criteria**:
- [ ] The commands under *Your steps* name the pull request by its branch, or the loop
      fills in the number after it opened the pull request.
- [ ] No command under *Your steps* holds a placeholder.
