# [XAS-100] loop.py find locates a container worktree without walking the checkout

**Status**: Open
**Priority**: Low
**Component**: `plugins/xxthunder-dev-skills/scripts/loop.py` (`find`), its tests
**Related**: [XAS-080](xas-080.md) (Resume finds a worktree made in a container)

**Summary**:
As the author, I want `loop.py find` to locate a worktree made in a container quickly and
without crashing, so that Resume stays fast in a large checkout.

**Description**:
XAS-080 added `loop.py find <checkout> <ID>`. When the main checkout's link back to a
worktree (`.git/worktrees/<name>/gitdir`) names a container path, `find` walks the whole
checkout to find the worktree whose `.git` file names `worktrees/<name>`. The final review of
the XAS-080 loop run parked four findings:

- The walk visits every directory of the checkout, other worktrees, `.venv`, build output and
  `.tox` included; only `.git` and `node_modules` are skipped, which guesses one ecosystem.
  The back-link names `<container root>/<relative path>/.git`, so trying `checkout /
  <suffix>` for each suffix of its path parts finds the worktree in O(depth) without a walk.
- An unreadable `.git` file anywhere in the checkout ends `find` with a `PermissionError`
  traceback, because `main` catches only `ValueError`.
- A corrupt `closed-loop.json` of any item ends `find` with exit 2 and a JSON message that
  does not name the file, so one broken state blocks Resume for every item.
- `test_worktree_env_plain_linked_worktree` stands under the `find` section of
  `tests/dev/scripts/test_loop.py` but tests `state` on a plain worktree.

**Acceptance Criteria**:
- [ ] `find` locates a worktree made in a container from the back-link's path suffixes, without walking the checkout
- [ ] An unreadable `.git` file or a corrupt state file is skipped or named in the message; `find` never ends with a traceback
- [ ] The plain-worktree `state` test stands under the `state` tests with a name that says what it covers
- [ ] The plugin's version is bumped in `plugin.json` and `marketplace.json`
