# [XAS-082] backlog.py and board.py write no em-dash

**Status**: Open
**Priority**: Low
**Component**: `plugins/xxthunder-dev-skills/scripts/backlog.py`, `plugins/xxthunder-dev-skills/scripts/board.py`, `tests/`, `plugins/xxthunder-dev-skills/skills/refinement/references/backlog-format.md`; the Board contract in the template's `asf/AGENTS.md`

**Summary**:
As the maintainer, I want the backlog and board scripts to write no em-dash, so that every repository and the board follow the global rule that bans it, also where the scripts write for them.

**Description**:
The global instructions ban the em-dash in new text (2026-11-08). Existing prose keeps it, but in three places the em-dash is a format token that a script writes into other repositories:

- `backlog.py` writes the table of contents line `- [ID — title](file)` into every backlog README, shortcuts included, which bans the em-dash in its own `.md` files.
- `backlog.py` prints and stores a missing priority as `—`.
- `board.py` writes and reads the card separator ` — ` (`TITLE_SEP`) that the Board contract defines.

**Scope Decisions**:
- **Only the tokens** (author, 2026-11-08): prose with em-dashes stays until it is edited for another reason; no bulk cleanup.

**Acceptance Criteria**:
- [ ] `backlog.py toc` writes table of contents lines without an em-dash, and the format reference says so
- [ ] A missing priority is written and printed without an em-dash, and an item that still carries `—` is read as before
- [ ] The Board contract and `board.py` use a card separator without an em-dash, and `board.py` still reads the cards on an existing board
- [ ] The plugin version is bumped
