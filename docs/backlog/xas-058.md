# [XAS-058] Eval runs record duration and cost, and the report shows them

**Status**: Open
**Priority**: Medium
**Component**: `evals/runner.py` (`parse_stream`, `run_one`, `report`), `tests/evals/`
**Related**: [XAS-056](xas-056.md) (where the gap was found), [XAS-055](xas-055.md) (needs the cost of a loop round), ADR-0012

**Summary**:
As the maintainer, I want every eval run to record its duration and cost, and the report
to sum them per case and per ref, so that I know what an eval session costs before a loop
runs one per round.

**Description**:
`skill-creator` records time and tokens per run and benchmarks them with mean ± stddev.
`evals/` records neither. The `result` event at the end of each `claude -p` stream already
carries the duration and the cost, so the runner only has to keep them in `result.json`.

XAS-055 has to set how many loop rounds may run before the loop stops and asks. That number
needs the cost of a round. A first figure, summed by hand on 2026-10-31 from the
`result` events of XAS-051's eval session: 12 runs cost about 2.81 USD, about 0.23 USD per
run.

**Acceptance Criteria**:
- [ ] `result.json` of each run holds its duration and cost, taken from the stream's
      `result` event; a run cut off before that event records none and says so
- [ ] `report` prints the mean duration and cost per case, and the total of the ref
- [ ] Tests cover a stream with a `result` event, one without, and the report's sums
