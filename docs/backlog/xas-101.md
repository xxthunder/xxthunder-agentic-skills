# [XAS-101] ✅ DONE - criticmark-review: the user reviews in the file, the agent replies in comment threads

**Status**: Done (2026-11-19)
**Priority**: Medium
**Component**: `plugins/xxthunder-dev-skills/skills/criticmark-review/`, `plugins/xxthunder-dev-skills/scripts/criticmark.py`

**Summary**:
As a developer who approves the agent's plans and drafts, I want to leave my feedback as comments in the file and have the agent answer in the same threads, so that the review happens in the file instead of in chat.

**Description**:
The [criticmark-review](https://github.com/cuinixam/criticmark-review) VS Code extension stores comment threads and suggestions as CriticMarkup in a markdown file, or in a `<file>.review` sidecar for other files. The skill tells the agent when to write a file for review, how to reply in each thread without editing anything else, and how to clean the file after approval. `scripts/criticmark.py` does every edit of the markup, with the same parser as the extension, so the agent never writes CriticMarkup by hand.

The skill comes from the author's own setup, where it has been in daily use since 2026-11, and was made portable for this plugin: no paths or folder conventions of that setup, and the script runs with `uv run`.
