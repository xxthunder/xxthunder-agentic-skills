# [XAS-052] The backlog's table of contents is split by status

**Status**: Open
**Priority**: Medium
**Component**: `plugins/xxthunder-dev-skills/scripts/backlog.py` (`toc`, `check`), `plugins/xxthunder-dev-skills/skills/refinement/references/backlog-format.md`, `plugins/xxthunder-dev-skills/skills/refinement/SKILL.md` (Step 1)

**Summary**:
As a user of `xxthunder-dev-skills`, I want the Open, In Progress and Done sections of the
backlog's table of contents in separate files, so that an agent that reads what is open or in
progress does not pay the tokens for every item ever closed.

**Description**:
`docs/backlog/README.md` holds one flat table of contents with three sections. The Done
section only grows: in this repository it is about half of the README's 8 KB, and it is the
part an agent needs least. `refinement` reads the whole README in Step 1, and an agent
orienting itself in a backlog does the same — the Done lines come along every time.

Splitting the sections lets a reader load the active backlog alone and open the Done list
only when it looks back (Cleanup, a search for an earlier decision).

The TOC is derived from the items ([ADR-0009](../adr/0009-backlog-items-are-the-truth-the-toc-is-derived.md)),
so the split is a change to what `backlog.py toc` writes, not to the items.

Raised on 2026-10-28.

**Open Questions**:
- Which files: Open and In Progress stay in `README.md` and Done moves to `done.md`, or one
  file per status?
- Is `backlog.py show` the better read for an agent than any TOC file — and should
  `refinement` Step 1 use it instead of reading the README?
- Does this need an ADR next to ADR-0009, or is it local to the TOC's layout?
- Migration: `toc` moves the existing Done lines on its first run in a consuming repo, and
  `check` accepts both layouts until then?

**Acceptance Criteria**:

      single-file README is migrated by the next `toc` run
- [ ] `backlog-format.md` and `refinement` describe the split; `refinement` Step 1 reads the

- [ ] Tests cover the split, the migration and a backlog without any Done item
- [ ] This repository's own backlog is regenerated in the new layout
